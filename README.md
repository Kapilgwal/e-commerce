# 🛍️ E-Commerce Website

A simple e-commerce web application built with **Django** (backend) and **Bootstrap** (frontend).  
This project demonstrates a basic online store with product listings, cart management, and checkout flow.  

---

## 🚀 Features
- User authentication (register/login/logout)
- Product catalog with categories
- Add to cart / remove from cart functionality
- Checkout process
- Responsive design with **Bootstrap**
- Admin dashboard for managing products & orders

---

## 🛠️ Tech Stack
- **Backend**: [Django](https://www.djangoproject.com/)  
- **Frontend**: [Bootstrap](https://getbootstrap.com/)  
- **Database**: SQLite (default, can be swapped with PostgreSQL/MySQL)  
- **Other Tools**: Django Admin, Django ORM
